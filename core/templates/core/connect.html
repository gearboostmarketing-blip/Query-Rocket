Setup

  1. Install the Query Rocket Connector plugin on {{ site.domain }} (Plugins → Add New → Upload, using query-rocket-connector.zip) and activate it.
  2. In WordPress, open Settings → Query Rocket and copy the connection key.
  3. Paste it here and connect. Query Rocket reads each page's SEO fields right away, and again after every crawl.

If the connection is refused, a security plugin (Wordfence, Sucuri) or Cloudflare rule may be blocking the WordPress REST API for outside requests.

How crawls run

Through the plugin, {{ site.domain }} loads its own pages from inside its server and sends them to Query Rocket, so firewalls, Cloudflare bot rules, and security plugins can't block the crawl. Fixes are checked live the same way. Needs Connector 1.2 or newer.
